: Understanding and maintaining source code is a critical yet time-consuming task in modern software development, especially when working with large or unfamiliar codebases. This project presents an AI-assisted code analysis and documentation tool designed to simplify this process and enhance developer productivity. The system allows users to input or upload Python code, which is then analyzed using Abstract Syntax Tree (AST) parsing to extract structural and logical information. Based on this analysis, the tool evaluates key software engineering metrics such as cyclomatic complexity, Halstead volume, and maintainability index to assess code quality. It also detects common coding issues, including unused variables, missing return statements, and inefficient constructs, providing clear explanations to support better understanding. In addition, the system integrates AI-driven capabilities to generate concise summaries and actionable insights for improving code. A key feature of the tool is its ability to automatically produce structured, industry-style documentation, reducing manual effort and improving readability. Developed using Python and Streamlit, the application offers an interactive dashboard interface with visualizations for complexity analysis. The generated documentation can also be exported as a PDF, making the tool useful for both academic and professional purposes.
